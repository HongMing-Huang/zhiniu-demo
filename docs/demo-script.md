## 录制要点

- 用 `adb shell screenrecord` + 多端 `scrcpy`，三段拼接。
- 关键操作放慢到 0.5x，字幕清晰。
- 覆盖 4 核心交互：列表→详情→AI诊股→聊天→卡片跳转。

## 四态全录

每页录到 Idle / Loading（骨架）/ Success / Error（重试），证明状态机完整。
