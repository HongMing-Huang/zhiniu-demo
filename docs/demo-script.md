## 录制要点

- 浏览器 1440×900 为主，主题与响应式镜头按需变焦；关键操作放慢 0.5x 并配字幕。
- 展示控制台无 error（DevTools 一闪而过即可）。
- AI 镜头确保后端在跑：`uvicorn app.main:app --port 8000`；「规则降级」镜头断开 Key 或后端均可复现。
- 每页覆盖 Idle / Loading（骨架）/ Success / Empty（搜「zzz」）/ Error（关后端刷新）五态各 1–2 秒。
- 多端拼图：`adb exec-out screenrecord` / `xcrun simctl io recordVideo`，或分别截 10s 静态演示。
